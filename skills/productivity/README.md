# Productivity

코드 외 워크플로우 스킬.

- **[smart-brevity](./smart-brevity/SKILL.md)** — Slack 공지·이메일·회의록·기획서를 Smart Brevity 원칙(Tease → Tell → Why it matters → Go deeper)으로 작성·리라이팅.
- **[create-design-md](./create-design-md/SKILL.md)** — 브랜드/제품의 DESIGN.md(컬러·타이포·컴포넌트 토큰)를 대화로 생성. 정보 부족 시 자동 질문.
- **[implement-design-system](./implement-design-system/SKILL.md)** — DESIGN.md를 Tailwind·shadcn 디자인 시스템 코드로 구현. 토큰 매핑·컴포넌트 생성·Provider 와이어링까지 일괄 처리.
