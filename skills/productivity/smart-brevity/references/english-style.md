# English Smart Brevity Rules

## Sentence Length

- ≤14 words per sentence (Hemingway benchmark)
- Split at conjunctions (and, but, because) when over limit
- Most important info in the first clause

## Muscular Verbs

Replace weak with strong:

| ❌ Weak | ✅ Strong |
|---|---|
| leverage | use |
| utilize | use |
| facilitate | enable / drive |
| implement | build / launch / ship |
| enhance | improve / sharpen |
| ensure | confirm / guarantee |
| provide | give / offer |
| be responsible for | own / lead |

## Hedging — Remove

- "might", "could", "perhaps", "possibly" → state it or cut it
- "we believe", "we think" → delete, state the fact
- "in order to" → "to"
- "due to the fact that" → "because"

## Bullet Formatting

- **Bold first 2–4 words** of each bullet for scanability
- One idea per bullet
- Parallel structure across bullets (all verbs or all nouns)
- No period at end of bullets (consistent)

## Numbers

- Always use figures: 3, not three; 50%, not fifty percent
- No space before %: 85%, not 85 %

## Capitalization

- Headlines: Sentence case (not Title Case For Every Word)
- Bold labels in bullets: Title Case allowed ("**Next steps:**")

## Forbidden Openers

- "I hope this email finds you well" — delete
- "Per our conversation" — delete, state the substance
- "Please find attached" — "Attached: [label]"
- "As previously mentioned" — delete, re-state if important

## Emoji

Not Smart Brevity. Use bold text and structure for visual hierarchy.
