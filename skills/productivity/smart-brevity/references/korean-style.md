# 한국어 Smart Brevity 규칙

## 문장 길이

- 1문장 ≤25자 권장
- 40자 넘으면 두 문장으로 분할
- 가장 중요한 정보를 앞 절에 배치

## 종결어미

문서 내 하나의 어미로 통일:
- 공지·기획서·이메일: `~합니다` (격식)
- 메모·내부 메시지: `~한다`도 허용
- 혼용 금지

## 한자어 → 쉬운 말

| 한자어 | 대체어 |
|---|---|
| 제고 | 높이기 |
| 증대 | 늘리기 |
| 추진 | 진행 |
| 도출 | 찾아내기 |
| 구현 | 만들기 |
| 활용 | 사용 / 쓰기 |
| 상기 | 앞서 말한 |
| 일환으로 | 위해 |
| 지속적으로 | 계속 |

## Hedging 제거

| ❌ 제거 | ✅ 대체 |
|---|---|
| ~인 것 같습니다 | ~입니다 |
| ~할 수도 있습니다 | ~합니다 / ~할 예정입니다 |
| ~로 판단됩니다 | ~입니다 |
| 아마 | (삭제) |
| 조금 | (삭제 또는 수치로) |
| 어느 정도 | (삭제 또는 수치로) |

## 주어 처리

- 불필요한 주어는 생략 (한국어 자연스러운 특성)
- 책임 소재가 중요한 문장은 주어 명시 ("유승재가 담당합니다")

## 굵은 글씨

- 헤드라인 또는 각 섹션 라벨에 사용
- Bullet 첫 2-4단어 강조 (`**다음 단계**: 내용`)
- 전체 문장 굵게 처리 금지 (희석됨)

## 금지 오프닝

- "안녕하세요" — 삭제, 헤드라인으로 바로 시작
- "감사합니다" — 마지막 문장 삭제
- "이번에 저희는" — 삭제, 결론부터
- "~을 공유드립니다" — "~입니다" 또는 헤드라인으로 대체

## 이모지

Smart Brevity는 이모지를 쓰지 않는다. 굵은 글씨와 구조로 시각적 위계를 만든다.
