# Smart Brevity 템플릿

## slack — ≤150자 목표

한국어:
```
[헤드라인 ≤15자, 동사형]
[핵심 1문장 — 가장 중요한 사실]
*왜 중요*: [독자에게 왜 관련 있는지 1문장]
• [액션 또는 핵심 정보]
• [기한 / 링크 / 담당자]
```

English:
```
[Headline ≤8 words, verb-driven]
[One sentence — most important fact first]
*Why it matters*: [1 sentence — reader's stake]
• [Action or key info]
• [Deadline / link / owner]
```

---

## email-memo — ≤400자 목표

한국어:
```
제목: [헤드라인 ≤20자]

[핵심 1문장 — 결론부터]

**왜 중요한가**
[1–2문장]

**내용**
• [bullet 1]
• [bullet 2]
• [bullet 3]

**다음 단계**
[액션 아이템 또는 결정 요청]
```

English:
```
Subject: [Headline ≤10 words]

[Lead sentence — conclusion first]

**Why it matters**
[1–2 sentences]

**The details**
• **Bold label:** [content]
• **Bold label:** [content]

**What's next**
[Action or ask]
```

---

## proposal — 자유 길이

한국어:
```
# [헤드라인]

[Big picture — 1문장 요약]

## 왜 중요한가
[2–3문장 — 문제, 기회, 또는 의사결정 맥락]

## 현황 / 수치
• [팩트 / 데이터]
• [팩트 / 데이터]

## 제안 / 다음 단계
• [제안 1]
• [제안 2]

## 결론
[한 줄 — Bottom line]
```

English:
```
# [Headline]

[Big picture — 1 sentence]

## Why it matters
[2–3 sentences]

## The numbers
• [Fact / data]
• [Fact / data]

## What's next
• [Proposal 1]
• [Proposal 2]

## Bottom line
[One sentence]
```
